# Практична робота №2 — Варіант 10: «Система накопичення енергії (Battery Storage)»

Дисципліна: «Розробка програмного забезпечення мобільних пристроїв», КПІ ім. Ігоря Сікорського.

Тема: меню, форми, MVVM, локальне сховище даних (практичні заняття № 5–8).

## Вміст

- `BatteryStorageApp/` — Android-проєкт (Kotlin, Jetpack Compose, Material 3, Navigation, ViewModel, Room)
- `Звіт_ПР2_Варіант10.docx` — звіт
- `screenshots/` — скриншоти застосунку для звіту

## Режими застосунку

Зверху екрана обирається заняття (ПЗ 5–8) і режим (ДЗ / Базовий / Середній / Просунутий).

| Заняття | Базовий | Середній | Просунутий | Домашнє завдання |
|---|---|---|---|---|
| ПЗ 5 — навігація | меню + 2 екрани-заглушки (NavController, NavHost) | екран-форма, аргументи маршруту, результат через SavedStateHandle | composable-компоненти, стан оператора й налаштувань, TopAppBar, адаптивний макет | вхід і реєстрація з валідацією |
| ПЗ 6 — форми | 2 поля, перевірка на порожні | email, пароль, helper text, валідація «на льоту» | складність пароля, C-rate за хімією, асинхронна перевірка email, стан завантаження | ім'я + email |
| ПЗ 7 — MVVM | ViewModel + LiveData, 2 екрани | StateFlow + combine, похідні стани, прогноз | пакети domain / viewmodel / ui, корутини, Loading / Success / Error | симулятор заряду (State у ViewModel) |
| ПЗ 8 — Room | Entity, DAO, Repository | 2 таблиці зі зв'язком, CRUD, пошук, локальне + віддалене джерело | 3 таблиці, @Transaction, агрегати, кеш, обробка помилок, фільтри й сортування | журнал вимірювань з CRUD |

## Запуск

Відкрийте теку `BatteryStorageApp` в Android Studio, дочекайтеся Gradle Sync і запустіть конфігурацію `app` на емуляторі (API 26+).

Тести: `gradlew :app:testDebugUnitTest` (28 тестів). Шлях із кирилицею заважає Gradle запускати тести на Windows, тому для прогону тестів проєкт варто скопіювати в теку з латинським шляхом.
